## 運用ルール

- **1 工程が完了するたびに、このファイルと英語版の両方へ追記する。** 工程の完了とコミットの前に必ず更新すること。
- 各エントリには次を必ず含める：工程番号・日付・使用した AI ツール・AI に任せた範囲・人間が判断した範囲・レビュー方法。

## 工程 1: 仕様の理解とベース環境の構築

- **日付:** 2026-08-01
- **使用ツール:** Claude Code (Claude Opus 5)
- **AI に任せた範囲:**
  - 課題ページを読み込み、要件（Next.js v16 以降・App Router・詳細画面はページとして実装・テストコード必須・プロダクション想定）を抽出。
  - `create-next-app` によるベースプロジェクトの生成（Next.js 16.2.12 / App Router / TypeScript strict / Tailwind CSS v4 / `src` ディレクトリ / `@/*` エイリアス）。
  - Vitest + React Testing Library (jsdom) によるテスト環境の構築と、動作確認用のスモークテスト 1 件の作成。
  - Node.js のバージョン固定（`.nvmrc` に 20.20.1。既定の Node 18 では Next.js 16 が動作しないため）。
  - `npm audit` で検出された `postcss` / `sharp` の脆弱性に対し、`package.json` の `overrides` でパッチ済みバージョンへ引き上げ（検出件数 0 件を確認）。
- **人間が判断した範囲:** この工程では、機能実装・アーキテクチャ設計は一切行っていない。**アーキテクチャ設計は次の工程で人間が AI と共に検討する**という方針のもと、意図的にベース環境の構築のみに留めている。
- **レビュー方法:** `npm run typecheck` / `npm run lint` / `npm test` / `npm run build` がすべて成功することを確認済み。
