<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query params `q` and `page` → server render | Free text from a user-controlled URL is read and interpolated into UI copy and outbound links |
| `RepoSummary.owner.login` and `RepoSummary.name` → outbound link URL | Values from the GitHub search response are used to build `/repos/{owner}/{name}?from=...` |
| Current URL string → `?from` query parameter | The full search URL is round-tripped through a link back to the detail page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Denial of service | Blank-keyword request storm at the page layer | mitigate | The page guards blank/whitespace before calling `searchRepositories`, so no request leaves the process. Phase 1 also guards, but doing it in the page is what gives the user the correct copy (D-09) — a defence in two places for two purposes |
