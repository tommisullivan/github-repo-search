<objective>
Ship SEC-01: real security response headers with a nonce-based Content-Security-Policy that never relies on `unsafe-inline` for scripts — implemented the way Next 16 actually supports (a `proxy.ts` generating a per-request nonce that Next applies to its own inline runtime scripts), and verified by loading both views from the production build and reading the violation reports, because a CSP that has not been driven is "a policy that looks strict but is not" (docs/SECURITY.md's own warning).

Purpose: the deployed app must not rely on framework defaults alone (Phase 4 success criterion 8). The header table has sat in docs/SECURITY.md as "Phase 4" since Phase 0 — this plan closes it and updates the doc from plan to shipped fact.

Output: `src/proxy.ts`, the tested `src/lib/csp.ts` builder, static headers in `next.config.ts`, `e2e/security-headers.spec.ts`, and the rewritten docs/SECURITY.md § Response headers.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → served HTML | Injected markup executing script is the classic XSS boundary; CSP is the response-side control |
| Any framing page → this app | Clickjacking via embedding; frame-ancestors/X-Frame-Options close it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Tampering (XSS execution) | every HTML response | mitigate | Nonce-based script-src with 'strict-dynamic'; no unsafe-inline; unit test pins the directive so a future loosening fails a named test |
| T-04-07 | Information disclosure | Referrer leakage of search terms | mitigate | `Referrer-Policy: strict-origin-when-cross-origin` (docs/SECURITY.md's stated reason) |
| T-04-08 | Elevation of privilege | Clickjacking via framing | mitigate | `frame-ancestors 'none'` + `X-Frame-Options: DENY` |
| T-04-09 | Spoofing | MIME confusion | mitigate | `X-Content-Type-Options: nosniff` |
| T-04-10 | Tampering | style-src concession scope creep | mitigate | Ladder applies to style-src only, on recorded evidence; script-src exempted by decision (D4-05/D4-06) and by unit test |
| T-04-SC | Tampering | npm installs | mitigate | Zero new dependencies in this plan; phase-wide check in 04-05's gate |
