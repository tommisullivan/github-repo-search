## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted URL segments (owner, repo) → outbound GitHub request | The Phase 1 repo unit encodes each segment separately and rejects blank args; this route inherits that guard by construction (single call to `getRepository`), and adds nothing that would let a caller reach around it |
| Untrusted `?from` query param → back link `href` | Guarded by `resolveBackTarget` (from 03-01), whose test names each rejection form |
| Thrown `GitHubRequestError` → user-visible copy | `error.tsx` renders generic Japanese retry copy, never `error.message` or the stack; production Next sanitises the message anyway but the code does not depend on that |
